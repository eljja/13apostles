## Symlink-Resilient Canonical Path Hardening (SR-CPH)

### Core Change

Specifically:
1. In `validate_and_resolve_path`, replace all instances of `os.path.abspath` with `os.path.realpath`. This forces the operating system to resolve all symbolic links, junctions, and relative segments to their true, physical canonical paths before conducting the commonpath prefix comparison.

```python
def validate_and_resolve_path(filename, workspace_dir=SAFE_WORKSPACE):
    """
    Validates that a path is securely within the designated safe workspace,
    resolving symbolic links to prevent link-traversal escapes.
    """
    os.makedirs(workspace_dir, exist_ok=True)
    workspace_real = os.path.realpath(workspace_dir)
    target_real = os.path.realpath(os.path.join(workspace_real, filename))
    
    try:
        common = os.path.commonpath([workspace_real, target_real])
        if common != workspace_real:
            raise PermissionError(f"Security Violation: Path traversal detected: {filename}")
    except ValueError:
        raise PermissionError(f"Security Violation: Invalid path target: {filename}")
        
    return target_real
```
